Ferrocene 25.05.1
=================

This is a security release to mitigate Cargo from `CVE-2026-66034`_, a security
vulnerability in libssh2 that exposes clients to remote code execution from
malicious servers.

While Ferrocene customers are encouraged to only use trusted remote git servers
for their dependencies, we still recommend customers to update to this security
release.

.. _CVE-2026-66034: https://nvd.nist.gov/vuln/detail/cve-2026-66034

Background
----------

In Ferrocene and the upstream Rust toolchain, Cargo is distributed with a
statically linked version of libssh2 as a dependency of libgit2 (which is also
statically linked into Cargo).

The Cargo distributed with Ferrocene 25.05.0, which is based on the upstream
1.86.0 release, includes libssh2 v1.11.1.

What Changed?
-------------

In Ferrocene 25.05.1, libssh2 has been entirely removed from the Cargo binary.
In addition, `net.git-fetch-with-cli` now always defaults to true.

There should be no observed behavioral differences for Ferrocene customers
upgrading from Ferrocene 25.05.0 to 25.05.1.
