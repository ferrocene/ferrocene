Next Ferrocene release
======================

This page contains the changes to be introduced in the upcoming Ferrocene
release.

New features
------------

A subset of the ``alloc`` library has been certified to IEC-61508 SIL 2 and ISO 26262 ASIL B.
This is in addition to the ``core`` library that is already certified for the same standards.
For more information, see the :doc:`user-manual:core/index` and :doc:`core-certification:index`.
