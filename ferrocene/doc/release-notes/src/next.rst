Next Ferrocene release
======================

This page contains the changes to be introduced in the upcoming Ferrocene
release.

New experimental features
-------------------------

Experimental features are not qualified for safety critical use, and are
shipped as a preview.

* The ``symbol-report`` and ``blanket`` coverage tools are now distributed as
  separate archives for all host platforms.

  The packages are available as:

  * ``symbol-report-${rustc-host}``
  * ``blanket-${rustc-host}``
